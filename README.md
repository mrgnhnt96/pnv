# pnv

Safely store environment variables in a public repository: encrypted YAML secrets, flavors and a `.pnvrc` config.

| Folder | What |
| --- | --- |
| [`dart/`](dart/) | The Dart package and CLI, published on [pub.dev](https://pub.dev/packages/pnv). See [`dart/README.md`](dart/README.md). |
| `rust/` | The Rust crate and `pnv` command (coming). |
| `spec/` | The shared format and test vectors both languages pass (coming). |

Dart releases are tagged `dart-v<version>`.
